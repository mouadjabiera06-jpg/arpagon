# budgetpro
Gérez votre budget simplement avec BudgetPro : revenus, dépenses par catégorie, objectifs d'épargne. Une app web complète dans un seul fichier HTML/CSS/JS — zéro dépendance, zéro serveur, zéro tracking. Fonctionne hors ligne, données 100% locales via localStorage. Téléchargez, ouvrez dans votre navigateur, c'est tout.
